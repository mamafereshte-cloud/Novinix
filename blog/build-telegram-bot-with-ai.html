ربات‌های تلگرام یکی از محبوب‌ترین روش‌های تعامل با کاربران هستند. با ترکیب تلگرام و هوش مصنوعی، می‌توانید ربات‌های هوشمندی بسازید که به سوالات پاسخ دهند، محتوا تولید کنند و حتی تصاویر بسازند. در این آموزش، ساخت یک ربات تلگرام با هوش مصنوعی را با استفاده از Python، OpenAI API و Telebot یاد می‌گیرید.

📌 پیش‌نیازها:

  • آشنایی مقدماتی با Python
  • یک حساب کاربری در OpenAI (برای دریافت API Key)
  • یک اکانت تلگرام و توکن ربات

مرحله ۱: ایجاد ربات در تلگرام

ابتدا باید یک ربات در تلگرام بسازید و توکن آن را دریافت کنید:

  1. ربات @BotFather را در تلگرام پیدا کنید.
  2. دستور /newbot را ارسال کنید.
  3. یک نام برای ربات انتخاب کنید.
  4. یک شناسه (Username) که به _bot ختم شود انتخاب کنید.
  5. توکن ربات را کپی کنید.

مرحله ۲: دریافت API Key از OpenAI

برای استفاده از هوش مصنوعی، به کلید API از OpenAI نیاز دارید:

  1. وارد platform.openai.com شوید.
  2. به بخش API Keys بروید.
  3. یک کلید جدید بسازید و آن را کپی کنید.

⚠️ توجه: کلید API خود را در کد ذخیره کنید و هرگز آن را به اشتراک نگذارید.

مرحله ۳: نصب کتابخانه‌های مورد نیاز

با استفاده از pip، کتابخانه‌های زیر را نصب کنید:

pip install pytelegrambotapi openai python-dotenv

مرحله ۴: کد ربات

کد زیر را در یک فایل bot.py قرار دهید:

import telebot import openai import os from dotenv import load_dotenv load_dotenv() # تنظیم توکن‌ها TELEGRAM_TOKEN = os.getenv('TELEGRAM_TOKEN') OPENAI_API_KEY = os.getenv('OPENAI_API_KEY') bot = telebot.TeleBot(TELEGRAM_TOKEN) openai.api_key = OPENAI_API_KEY @bot.message_handler(commands=['start']) def send_welcome(message): bot.reply_to(message, "👋 سلام! من یک ربات هوشمند هستم. هر سوالی داری از من بپرس!") @bot.message_handler(func=lambda message: True) def handle_message(message): try: response = openai.ChatCompletion.create( model="gpt-3.5-turbo", messages=[ {"role": "system", "content": "تو یک دستیار هوشمند و مفید هستی."}, {"role": "user", "content": message.text} ], max_tokens=500 ) reply = response.choices[0].message.content bot.reply_to(message, reply) except Exception as e: bot.reply_to(message, f"❌ خطایی رخ داد: {str(e)}") if __name__ == "__main__": bot.infinity_polling()

مرحله ۵: اجرای ربات

برای اجرای ربات، فایل را در ترمینال اجرا کنید:

python bot.py

حالا ربات شما فعال است و می‌توانید در تلگرام با آن چت کنید!

مرحله ۶: انتشار ربات

برای اینکه ربات همیشه فعال باشد، می‌توانید آن را روی یک سرور (مانند Heroku، Railway یا یک VPS) میزبانی کنید.

  • افزودن دکمه‌های شیشه‌ای (Inline Keyboard)
